## 1. 简介

OpenFocus 是一款面向科研人员、工程师和图像处理从业者的专业多焦点图像融合桌面应用。软件通过先进的配准与融合算法处理多焦点图像序列，生成全景深的全清晰图像。

### 核心功能

- **多焦点图像融合**：将多张不同焦点的图像合成为一张全清晰图像
- **多种融合算法**：引导滤波、DCT、DTCWT、GFG-FGF、StackMFF-V4（深度学习）
- **图像配准**：使用 ECC 或单应性变换对齐存在偏移的图像序列
- **Wipe 对比视图**：通过 A/B 分割线视图直观检查配准质量、对比不同结果
- **批处理**：同时处理多个图像文件夹
- **无头命令行**：支持脚本化调用与 CI 集成
- **灵活导出**：结果可保存为单张图像、文件夹或 GIF 动画
- **图像变换**：旋转、翻转、缩放整个图像栈
- **标签标注**：为配准栈和输入栈添加文字标签
- **设置持久化**：偏好设置、界面语言、最近打开的图像栈在重启后自动恢复

### 支持的输入格式

- 图像文件：JPG、PNG、BMP、TIFF 及其他常见格式
- 视频文件：MP4、AVI、MOV、MKV、WMV、FLV、WEBM（自动解码为图像序列）
- 包含按序号命名的图像序列的文件夹

### 支持的输出格式

- 单张图像：JPG、PNG、BMP、TIFF
- 图像序列：以文件夹形式保存
- 动画：GIF 格式

## 2. 快速开始

### 启动应用

安装完成后，通过以下方式启动 OpenFocus：

1. **Windows（可执行包）**：双击 OpenFocus 快捷方式或可执行文件
2. **源码运行**：在激活的 conda 环境中执行 `python main.py`

首次启动会显示深色主题的主界面。首次启动可能需要 30–60 秒加载，请耐心等待。

### 快速上手流程

1. 导入图像序列（文件 → 打开文件夹，或直接拖拽）
2. 在右侧面板配置融合参数
3. 按需勾选配准选项
4. 需要时调整核大小
5. 点击"渲染"开始处理
6. 导出结果

## 3. 主界面概览

OpenFocus 界面分为三个主要区域：

### 左侧面板：图像显示区

窗口左侧以分屏方式显示图像：

- **源图像面板**：显示输入图像序列
- **结果图像面板**：显示融合或配准结果
- **导航滑块**：拖动每个面板下方的滑块浏览帧
- **图像信息标签**：显示当前帧位置和图像尺寸

拖动面板之间的分割条可以调整面板大小。

### 右侧面板：控制面板

右侧面板自上而下排列所有配置项：

1. **融合设置**：选择融合算法和核大小
2. **配准设置**：启用/禁用对齐方法
3. **操作按钮**：恢复默认、开始渲染
4. **源图像列表**：显示已加载的所有帧
5. **输出列表**：显示已生成的结果

### 菜单栏

顶部菜单栏提供全部功能入口：

- **文件**：导入/导出操作、最近打开列表
- **编辑**：图像变换和标签
- **批处理**：批量处理
- **设置**：GPU 加速、语言、瓦片、配准、线程数等配置
- **帮助**：环境信息与联系方式

## 4. 导入图像与视频

### 打开图像文件夹

1. 点击 **文件 → 打开文件夹** 或按 `Ctrl+O`
2. 选择包含图像序列的文件夹
3. 弹出降采样对话框——选择缩放比例
4. 点击确定加载图像

软件会自动：
- 按文件名检测并排序图像文件
- 在源图像面板显示第一帧
- 将所有帧填入源图像列表

### 打开视频文件

1. 点击 **文件 → 打开视频** 或按 `Ctrl+Shift+O`
2. 选择视频文件（支持 MP4、AVI、MOV、MKV、WMV、FLV、WEBM）
3. 视频会自动解码为逐帧图像
4. 每一帧成为图像栈的一部分

### 最近打开

每次打开的图像栈都会记录在 **文件 → 最近打开** 中（最多 8 条）。按 `Alt+1` … `Alt+8` 可直接重新打开对应条目。重复打开同一栈会自动置顶；文件已不存在的条目会提示移除；**清空最近列表**可一键清空。

### 拖拽导入

将文件夹直接拖到应用窗口即可导入。将更多文件拖到已加载的栈上可以追加图像（会先做尺寸校验）。

### 清空图像栈

点击 **文件 → 清空图像栈** 或按 `Ctrl+W` 移除所有已加载的图像。

## 5. 浏览与导航图像

### 浏览图像栈

- **滑块**：拖动源面板下方的滑块浏览帧
- **文件列表**：点击右侧面板源图像列表中的任意文件名

- **适应窗口**：双击图像在适应窗口和 100% 视图间切换
- **平移**：按住拖动即可在面板内移动图像

### 同步导航

在源面板中导航时，结果面板会显示对应的结果帧（如果存在）。

## 6. Wipe 对比视图

Wipe 视图将两张图像叠加在同一画面中，中间有一条可拖动的垂直分割线，让配准偏差和质量差异跨越分割线时一目了然。

### 进入 Wipe 视图

1. 先渲染出至少一个结果（融合或配准）
2. 点击结果面板标题栏右上角的 **对比** 开关
3. 结果区域切换为对比视图；再次点击 **对比** 返回普通视图

### 界面说明

- **A 侧（分割线左侧）**：源帧——默认跟随源面板滑块
- **B 侧（分割线右侧）**：最近一次渲染结果
- **白色分割线 + 圆形手柄**：水平拖动即可移动分割位置
- 让穿过分隔线的边缘在两侧错位，可以直观暴露并排面板难以察觉的配准偏差

### 选择对比内容

对比视图底部的工具条每侧一组控件：

- **A 侧** — 勾选 **跟随源图**（默认）实时跟随源面板滑块；取消勾选后滑块解锁，可锁定任意帧
- **B 侧** — 勾选 **最新结果**（默认）始终显示最新渲染；取消勾选后拖动滑块浏览输出历史

两侧实时更新：新渲染、源滑块移动、帧删除都会立即反映到对比视图中。

### 缩放与平移

对比视图的两张图共享同一变换：

- **缩放**：鼠标滚轮（围绕光标位置缩放）
- **平移**：在分割线以外区域按住拖动
- **复位**：双击

Wipe 模式与 ROI 模式共用结果面板，进入其一自动退出另一个；清空图像栈也会退出 Wipe 模式。

## 7. 图像配准

图像配准用于校正图像栈中帧与帧之间的空间偏移。当图像存在轻微位移或透视变化时，配准是必不可少的步骤。

### 配准方法

#### ECC（增强相关系数）

- 基于优化寻找相关性最大的对齐方式
- 适合细微偏移
- 提供亚像素级精度
- 比单应性慢但更精确

#### 单应性（Homography）

- 基于特征点匹配（SIFT/ORB 特征）
- 处理更大的几何变换
- 初始对齐比 ECC 快
- 适合透视变化明显的图像

### 启用配准

1. 在右侧面板找到 **配准** 组
2. 勾选 **Align (ECC)** 启用 ECC 对齐
3. 勾选 **Align (Homography)** 启用单应性对齐
4. 两者可以同时使用以获得更好效果

### 何时需要配准

- 图像存在可见偏移
- 手持拍摄
- 场景存在视差（近景物体在帧间移动）
- 结果出现重影或拖尾

### 配准设置

通过 **设置 → 配准设置** 访问：

- **下采样宽度**：控制特征提取的预处理分辨率（默认 1024px）
- 数值越低处理越快，精度可能下降
- 数值越高处理越慢，精度可能提升

## 8. 图像融合方法

OpenFocus 提供五种融合算法，各自适用于不同类型的图像。

### 引导滤波（默认）

- **算法**：使用引导滤波进行边缘保持融合
- **适用**：通用场景，速度与质量均衡
- **优点**：边缘保持好，处理快
- **参数**：核大小（1–51，仅奇数）
  - 小核：局部细节多，可能有噪声
  - 大核：结果更平滑，抑噪更好

### DCT（离散余弦变换）

- **算法**：基于 DCT 系数的频域融合
- **适用**：纹理丰富的图像、科学成像
- **优点**：保留精细纹理，数学原理可靠
- **参数**：核大小控制处理窗口

### DTCWT（双树复小波变换）

- **算法**：多尺度小波域融合
- **适用**：具有多层次细节的复杂场景
- **优点**：出色的多尺度分析能力，方向性好
- **参数**：滤波操作的核大小

### GFG-FGF（广义四邻域梯度 - 快速引导滤波）

- **算法**：基于梯度的融合 + 快速引导滤波
- **适用**：焦点区域清晰的图像
- **优点**：速度快，焦点区域检测好
- **参数**：核大小可调

### StackMFF-V4（深度学习）

- **算法**：神经网络融合（需要 PyTorch）
- **适用**：追求最高质量的结果
- **优点**：当前最先进的融合质量
- **要求**：安装 PyTorch，可选 CUDA GPU
- **注意**：未安装 PyTorch 时该选项不可用

### 选择融合方法

1. 在右侧面板找到 **融合** 组
2. 点选对应的融合算法单选框
3. 按需调整核大小
4. 点击 **渲染** 开始处理

### 算法对比指南

| 算法 | 速度 | 质量 | 适用场景 |
|------|------|------|----------|
| 引导滤波 | 快 | 好 | 通用 |
| DCT | 中 | 好 | 纹理 |
| DTCWT | 中 | 很好 | 复杂场景 |
| GFG-FGF | 快 | 好 | 焦点区域 |
| StackMFF-V4 | 慢（GPU） | 极好 | 最高质量 |

## 9. 图像变换

### 旋转

1. 点击 **编辑 → 旋转**
2. 选择旋转类型：
   - **顺时针 90°**：全部图像右转 90 度
   - **逆时针 90°**：全部图像左转 90 度
   - **180°**：上下颠倒

### 翻转

1. 点击 **编辑 → 翻转**
2. 选择翻转类型：
   - **水平翻转**：左右镜像
   - **垂直翻转**：上下镜像

### 缩放

1. 点击 **编辑 → 缩放**
2. 在对话框中输入缩放参数
3. 整个图像栈按比例缩放

### 变换顺序

变换作用于整个图像栈，并保持帧间的对齐关系。

## 10. 标签与标注

### 添加标签

1. 确保已有渲染结果或已加载图像
2. 点击 **编辑 → 添加标签**
3. 在对话框中配置标签格式、起始值、步长、位置、字体和范围
4. 标签会应用到配准栈和输入栈

### 删除标签

- **删除已配准栈标签**：移除对齐图像上的标签
- **删除输入栈标签**：移除原始图像上的标签

通过 **编辑 → 删除标签** 子菜单访问。

## 11. 设置与配置

### 瓦片设置（内存优化）

大图默认使用分块（瓦片）处理以避免内存问题。

通过 **设置 → 瓦片设置** 访问：

- **启用瓦片处理**：关闭后强制整图处理（大图可能内存不足）
- **分块大小**：每块的处理尺寸（默认 1024px）
- **重叠**：块间重叠量，用于无缝拼接（默认 256px）
- **阈值**：图像超过该尺寸时启用瓦片处理（默认 2048px）

**建议**：
- 分块越小：内存占用越低，处理越慢
- 分块越大：内存占用越高，处理越快
- 结果出现接缝时增大重叠量

### 配准设置

通过 **设置 → 配准设置** 访问：

- **下采样宽度**：配准特征提取的预处理分辨率
  - 默认 1024px
  - 调低提速，调高提精度

### 线程数设置

控制 CPU 并行处理：

通过 **设置 → 线程数设置** 访问：

- 设置工作线程数（默认 4）
- 与 CPU 核心数匹配可获得最佳性能
- 数值越高处理越快，CPU 占用越高

### GPU 加速开关

OpenFocus 只有 StackMFF-V4 神经网络模型使用 GPU（CUDA/MPS）；经典算法始终在 CPU 上运行。

- 通过 **设置 → GPU 加速** 开关切换
- 取消勾选后全部强制使用 CPU——GPU 驱动异常时非常有用
- 禁用期间状态面板的 GPU 项显示 `CPU*`
- 设置对下一次渲染生效，并会被记住

### StackMFF-V4 批量大小

通过 **设置 → StackMFF V4 Batch Settings** 访问：

- 控制神经模型每批处理的瓦片数量（默认 2）
- 数值越大越快，但内存占用越高

### 设置持久化

以下设置在应用重启后自动恢复：线程数、瓦片参数、配准下采样宽度、StackMFF-V4 批量大小、GPU 加速开关、界面语言，以及最近打开的图像栈。设置对话框确认即保存；应用关闭时再次整体保存。偏好按用户存储在 `OpenFocus/OpenFocus.ini`（QSettings INI 格式）。

### 界面语言

随时通过 **设置 → Language → English / 中文** 切换，立即生效并被记住。

## 12. 批处理

自动处理多个文件夹：

1. 点击 **批处理 → 批处理** 菜单
2. 在批处理对话框中：
   - **添加文件夹**：选择包含图像序列的文件夹
   - **移除文件夹**：从列表移除选中项
   - **清空全部**：移除所有文件夹
3. 配置输出设置：
   - **保存到子文件夹**：在各输入文件夹内生成结果
   - **保存到同目录**：与输入保存在一起
   - **自定义目录**：指定输出位置
4. 检查当前融合/配准设置
5. 点击 **开始批处理** 运行

批处理对话框实时显示进度，随时可以取消。

### 批处理说明

- 使用与手动处理相同的融合和配准设置
- 每个文件夹独立处理
- 可设置 JPG 输出质量（默认 100）
- 勾选"保存对齐图像栈"可额外输出配准后的逐帧图像

## 13. 导出结果

### 保存单张结果

1. 在输出列表中选择要保存的结果
2. 点击 **文件 → 保存** 或按 `Ctrl+S`（也可以右键输出条目选择"另存为"，或直接把输出条目拖出软件到文件夹）
3. 选择格式和位置
4. 保存

### 保存配准栈

1. 点击 **文件 → 保存堆栈 → 已配准堆栈**
2. 选择保存格式：
   - **保存为文件夹**：每帧对齐图像保存为单独文件
   - **保存为 GIF**：生成对齐序列的动画

### 保存输入栈

1. 点击 **文件 → 保存堆栈 → 输入堆栈**
2. 选择保存格式：
   - **保存为文件夹**：原始帧保存为单独图像
   - **保存为 GIF**：生成输入序列动画

### 导出格式

- **JPG**：有损压缩，质量-体积比好
- **PNG**：无损，支持透明
- **BMP**：无压缩，质量最高
- **TIFF**：高质量
- **GIF**：动画格式

## 14. 命令行界面

OpenFocus 支持无界面运行——适合脚本流水线和 CI 集成。在 Python 环境中（或打包版可执行文件旁）：

```bash
# 使用默认引导滤波融合一个文件夹
python main.py --input ./stack_folder --output ./result/fused.png

# DTCWT + ECC 配准，8 线程
python main.py -i ./stack_folder -o ./result/fused.png -m dtcwt -a ecc -t 8

# StackMFF-V4 强制 CPU + 自定义瓦片尺寸
python main.py -i ./stack_folder -o ./result/fused.png -m stackmffv4 --cpu --tile-size 512

# 显式文件列表；也接受视频文件作为输入
python main.py -i img1.jpg img2.jpg img3.jpg -o fused.png -m gfgfgf
```

| 参数 | 说明 |
|------|------|
| `--input, -i` | 图像文件夹、视频文件，或一个/多个图像文件 |
| `--output, -o` | 输出图像路径（扩展名决定格式） |
| `--method, -m` | `guided_filter`（默认）、`dct`、`dtcwt`、`gfgfgf`、`stackmffv4` |
| `--align, -a` | `none`（默认）、`homography`、`ecc`、`both` |
| `--kernel, -k` | guided_filter/dct/gfgfgf 的核大小（自动取奇） |
| `--threads, -t` | 工作线程数（默认 4） |
| `--batch-size` | StackMFF-V4 瓦片批大小（默认 2） |
| `--cpu` | 即使有 GPU 也强制 CPU |
| `--downscale` | 配准特征提取的下采样宽度 |
| `--tile-size` | 大图的瓦片分块尺寸 |

退出码：`0` 成功，`1` 处理错误，`2` 用法错误。`python main.py --help` 打印全部参数；以普通路径启动（`python main.py C:\stack`）仍会打开 GUI 并自动加载该文件夹。

## 15. 键盘快捷键

## 16. 故障排除

### 常见问题

#### 提示"No Images Loaded"

- 先导入图像文件夹或视频
- 检查文件夹内是否包含受支持的图像格式

#### 融合结果模糊或有重影

- 启用图像配准（ECC 和单应性可以同时勾选）
- 确认融合前图像已正确对齐
- 尝试其他融合算法
- 增大核大小获得更平滑的结果

#### StackMFF-V4 不可用

- 安装 PyTorch：`pip install torch torchvision`
- GPU 加速请安装 CUDA 版 PyTorch
- 通过 **帮助 → 环境信息** 检查安装状态

#### 内存不足（OOM）

- 在 **设置 → 瓦片设置** 中启用瓦片处理
- 减小分块尺寸
- 使用更小的核
- 将图像缩放到更小的尺寸

#### 配准失败

- 每次只尝试一种配准方法
- 在 **设置 → 配准设置** 中减小下采样宽度
- 确保图像有足够的对比度和特征

#### 处理速度慢

- 在 **设置 → 线程数设置** 中增加线程数
- 使用更强的 CPU
- 降低图像分辨率
- 改用更简单的融合算法（引导滤波代替 StackMFF-V4）

#### Windows 首次启动弹出 SmartScreen 警告

发布包未做数字签名。点击 **更多信息 → 仍要运行**。解压后的首次启动可能需要 30–60 秒。

#### macOS 提示"无法打开"或"已损坏"

应用未签名未公证。将 `OpenFocus.app` 移入"应用程序"后，在终端执行：

```bash
xattr -cr /Applications/OpenFocus.app
```

或右键点击应用选择 **打开**。发布的 macOS 包面向 Apple Silicon（M1/M2/M3/M4）；Intel Mac 请从源码运行。

### 获取帮助

1. **环境信息**：点击 **帮助 → 环境信息** 检查安装状态
2. **联系方式**：点击 **帮助 → 联系我们** 获取支持信息

## 附录：融合算法细节

### 引导滤波

引导滤波使用引导图像进行边缘保持平滑。它计算引导图像与输入图像之间的局部线性变换，再将其应用于输出。该方法在降噪的同时能出色地保留边缘。

### DCT（离散余弦变换）

DCT 将图像变换到频域，基于系数幅值做出融合决策。高频分量（细节）被保留，低频分量（平滑区域）按局部能量合并。

### DTCWT（双树复小波变换）

DTCWT 提供图像的多尺度、多方向分解。它捕获不同尺度和方向上的特征，使融合规则能够同时保留纹理与结构信息。

### GFG-FGF

该算法使用广义四邻域高斯方法度量局部焦点，并结合快速引导滤波精炼权重图，高效识别并合并合焦区域。

### StackMFF-V4

基于深度学习的方法，使用在大规模多焦点图像对上训练的神经网络。网络自动学习最优融合策略，配置得当时可提供当前最先进的结果。
