# OpenFocus 界面与交互规范

## 信息层级

- 工作区优先展示图像、操作控件和完成任务所需的状态；不要在按钮、选项或输入框下方常驻重复的功能解释、副标题或操作说明。
- 把功能含义、参数说明、使用方法和真实快捷键放在对应控件的鼠标悬停提示中。说明要简洁；同一功能已有提示时应合并，不要覆盖原有信息。复合控件的文字、指示器和输入区域都应能显示相同提示。
- 悬停提示应提供补充信息；控件文字完整可见且没有额外说明时，不要只重复文字。文字被省略时保留完整内容，图标按钮及必要说明仍提供提示。
- 控件本身必须有清楚的名称与当前值，不能依靠悬停提示才能找到或理解基本操作。需要辅助技术读取的说明同时设置无障碍描述。
- 加载或计算进度、失败原因、当前选择、重要输出状态、空状态，以及用户作出决定前必须知道的风险或限制，必须即时可见，不能仅藏在悬停提示中。完成后不再需要的成功状态应及时收起。
- 帮助文档、首次使用引导和确认对话框中的必要说明不是工作区副标题；应按其用途保留。

## 布局与交互

- 图像调整工作流让预览占主要面积，设置与结果并排；窗口较小时优先保留预览和操作按钮，设置区可滚动。滑块与数字输入保持同步，并提供恢复默认的方法。
- 前后对比应标明两侧含义并提供可见的拖动手柄；滚轮缩放、平移和复位不得改变图像数据。调整期间保留用户的观察位置。
- 长文本、十二种语言、明暗主题、高 DPI 和小窗口均需保持控件和数值完整可见；说明只使用本地化字符串。
- 验收时在实际窗口中检查布局、悬停提示、缩放及主要操作，并验证错误、进度和取消流程仍然可见且有效。
