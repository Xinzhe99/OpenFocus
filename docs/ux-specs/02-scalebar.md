## 2. 界面和操作流程

左侧可滚动表单按“对象与范围 → 标定 → 放置 → 外观”排列，右侧显示真实目标。顶部标明对象名、帧号、尺寸、位深；预览下显示有效标定、条长物理值和对应像素数。底部固定“取消 / 应用并关闭”。预览提供适应窗口、100% 和栈切帧。

每个目标最多一条比例尺。编辑加载现有配置；删除只作用于选定目标，也保留全部删除。目标区分源栈、配准栈、具体输出，不以“结果”含糊覆盖多个域。栈范围复用标签的全部/当前/自定义合法范围与帧身份规则；单幅输出不显示帧区间。

### SC-11 显式标定（P0）

- 两种模式：“使用图像元数据 / 手动标定”。不再依靠 `0=自动` 让用户猜规则。自动显示检测值、单位与来源；缺少元数据时说明不可用。
- 手动模式明确“覆盖该目标元数据”；输入统一定义为**原始图像像素尺寸**，单位 µm/原始像素。支持小数精度，拒绝零、负数和非有限值。
- 同时显示原始值、实际采样比例、最终绘制值。例如 0.5 µm/原始像素、50%、1 µm/当前像素。
- 实际尺寸比需考虑整数取整；裁剪只改变视野/偏移，不改变像素尺寸。标定沿配准参考坐标系传递；若变换无法支持可信的统一标定，标为未标定，不从当前栈借值。
- 输出发布时固定标定来源、原始值、实际变换及有效值；修饰子输出继承父输出标定。历史输出不受后来加载/缩放影响。
- 旧正数手动值迁移为手动，0 为自动；旧工程已缩放但没有足够原始信息时显示“标定需确认”，允许查看和无标尺导出，不能猜一个可信物理值。

### SC-12 绘制与预览（P0/P1）

统一在目标原生像素坐标系求条长、文字、边距和字体，再缩放显示。预览不能独立套另一组最小条长/字号。最终图形长度和文字来自同一几何结果；尺寸不足时选另一合法长度或明确“图像太小，无法放置有效比例尺”，不能改图形不改文字。

角落位置保留；custom X/Y 增加百分比数字框并与滑块同步。显示实际使用字体及替代提示。uint16 路径完整传递所有样式，显示用标准转换，未覆盖像素不变。自动单位沿用 nm/µm/mm；指定条长和固定显示单位列为 P2，可独立增加，不阻碍正确性修复。

预览必须跟随目标及当前帧。无目标、无标定、无适用范围、无法放置均就地说明并禁用提交；不能显示“已启用”却什么也没有。首次加载在绘制前提交新栈标定，不依靠切帧修正首屏。

### SC-13 草稿与持久化（P0）

所有预览接收局部草稿，不写 parent。取消/Esc/× 无副作用；确认和移除各形成一次配置撤销、dirty 和恢复快照。resize 撤销同时恢复采样映射及标注几何。

工程保存完整模式、单位基准、原始/有效标定及来源、目标/帧范围、位置、颜色、字体、字号、粗体、对齐、custom 坐标和启用状态。偏好仅作新配置默认值，工程值完整覆盖，不能夹带上次工程字段。输出像素未随工程保存时，绑定目标保持未载入，不自动重绑。

## 3. 全部绘制出口

| 出口 | 明确上下文与要求 |
|---|---|
| 源主画布、源文件夹、源 GIF、源多页 TIFF | 显式 source 及帧身份，不能依赖默认 output |
| 配准主画布、A/B、配准文件夹/容器 | 配准参考域和当前帧；与目标范围匹配 |
| 输出画布、Ctrl+S、右键、拖出、导出全部 | 指定 `output_id` 自身标定，统一完整样式 |
| 批处理 | 每任务标定和完整配置；摘要说明自动检测或手动覆盖，不借当前主栈 |
| CLI | 保留手动优先、缺标定报错及无 GUI 能力，更新公用绘制函数的全部调用方 |

导出启动时冻结配置。已烧入比例尺的 batch 文件标明像素已含标注，再导出默认保留现有内容；移除显示配置不宣称能擦掉文件中的旧图案。继续使用 `imwrite_auto`，不将显示缓存作为保存像素。
