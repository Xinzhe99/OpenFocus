# 修饰结果：来源说明、快捷键与发布保护

状态：待实现的增量规范。基准 v1.67.0，配合既有 [RETOUCH_SPEC](../RETOUCH_SPEC.md)、[共用规范](00-shared.md)和[导出规则](09-export-project-recovery.md)。本轮实际查看[1280×820工作区](evidence/retouch_zh.png)及[960×640工作区](evidence/retouch_small_zh.png)，没有重新执行全部笔画、发布和关闭测试。

## 1. 已有能力与剩余问题

来源绑定、稳定输出身份、缩略图/滑块/可编辑帧号、双画布共享视图、数值画笔、源帧/还原工具、笔画事务、精确dirty、撤销/重做、暂看、全屏、应用失败保留会话、关闭三选项和未导出保护都已实现。此次完善剩余边界，不重做修饰引擎。

| ID | 优先级 | 当前代码事实与影响 |
|---|---|---|
| RT-01 | P1 | RenderContext已有配准/ROI/来源，标题和状态主要显示输出名/尺寸/位深及源名。[INFERENCE] 用户不易判断不可取材区域及父结果关系。 |
| RT-02 | P1 | 工具帮助固定说从选中帧取材，切到还原未更新；清晰度图混入source QImage，右侧暂看也使用它。[INFERENCE] 还原说明错误，暂看不再是纯源显示。 |

## 2. 来源与布局（RT-10，P1）

顶部保留输出名称/尺寸/位深，增加紧凑摘要“方法 · 配准/未配准 · N帧 · 全图/ROI”。“来源详情”显示父输出、实际帧身份及已记录范围；缺字段写未记录，不从当前主窗口补猜。

源画布提供不可取材域遮罩，状态区分“ROI外”和“该帧无有效像素”。保留现有无效光标和落笔提示。专注结果模式仍显示当前帧、来源摘要及暂看入口，不因隐藏源画布使取材对象不可知。

现有 `build_render_context` 仅保留ROI裁片，测试亦约束ROI外不可取材；旧RETOUCH_SPEC中“贴回后可用全图源”的文字与现状不一致。本轮按真实覆盖域解释并修正文档，**不通过放宽掩码扩大来源**。来源缺失仍禁止编辑；可选元数据缺失不等于像素来源丢失。

TIFF容器/页号、融合预处理和顺序等需由渲染时写入上下文才能展示，不能根据当前文件列表事后拼出“完整来源”。

## 3. 工具与辅助显示（RT-11，P1）

- 源帧画笔：复制当前帧对应位置；还原画笔：恢复到本次打开的结果。切工具同步更新说明。
- 提供可见快捷键入口；保留B/E工具、F适应、100%、F11及源帧导航。
- 暂看右侧明确标“修饰前”或“当前源帧，暂看中”，禁用绘制；释放恢复工作图，不改dirty。
- 清晰度辅助只影响左侧辅助显示；右侧“暂看源帧”用未混合热图的源显示。热图不能进入编辑像素。
- 清晰度显示计算中/就绪/失败，失败可重试，普通绘制继续；取消/关闭使用合作停止及finished通知，不在GUI线程等待整段计算，晚到图不更新窗口。

## 4. 键盘、控件与模型一致（RT-12，P0/P1）

所有直径修改入口更新同一个模型，再同步数字、滑块、光标。键盘`[`/`]`与控件结果一致。活动笔画期间拒绝直径、帧和工具变更，界面也不先变后偷偷延迟生效。

已捕获的临时键释放清理先于输入焦点排除；焦点从画布移到内部控件也解除暂看/平移。字母、数字和标点画布快捷键仅在画布上下文使用，输入框保持正常编辑。画布按住Tab暂看保留，Shift+Tab必须能离开画布，其他控件Tab仍导航。

按钮与Ctrl/Cmd+Enter共用可执行条件：真实dirty、空闲、非暂看、无活动笔画、尚未发布。普通Enter不隐式应用；禁用按钮时快捷键同样无效。补齐既有文档承诺的`+/-`缩放，沿用视图范围和中心规则。

## 5. 应用、失败和退出（RT-13，P0）

主要动作“应用为新输出”，持续说明“加入输出列表，仍需导出文件”。发布期间显示正在创建且禁止重入。

发布先准备结果/显示，再一次性提交输出和选择；**成功后才淘汰历史**。失败完整保持原输出身份、顺序、数量、选择、当前结果和编辑缓冲，显示可重试原因。不能只保证新条目删除却丢失旧条目。原图保持不变，未导出受保护项仍不被淘汰。

窗口内状态称未应用；成功发布后列表独立显示未导出，不拼入用于命名的label。全部成功导出入口统一更新同一output_id的状态、tooltip、路径和版本；工程保存不解除图像保护。

保留关闭三选项，默认继续编辑。应用失败留窗口；导出取消/失败保留未导出标记。目录式导出默认避让实际磁盘文件，部分失败列对象/路径/原因并阻止保护流程自动退出，详见导出规格。

更新重启也走此关闭协议；不能以“自动恢复”名义丢弃未应用笔画或未导出像素。

## 7. 实施与边界

优先修实际画笔参数、发布回滚和导出文件保护；再完善来源/辅助显示与键盘焦点。沿用RetouchDocument笔画事务和现有输出身份；不重写历史系统、不新增自动选帧或克隆变形工具。

承接 `tests/test_retouch.py` 与输出导出回归，场景须覆盖真实像素覆盖、历史满时失败、焦点切换和发布一次性。不要为控件连线或固定措辞写测试。同步旧RETOUCH_SPEC中ROI/快捷键描述、十二语言及手册；本轮未运行这些增量验收。
