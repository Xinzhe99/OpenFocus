## 2. 目标布局与主要流程

入口保留“工具 → 标签”，主动作改为“管理标签…”。顶部显示目标名称、尺寸、位深；左侧标签列表；中间可滚动属性；右侧真实目标预览；底部固定“取消 / 应用并关闭”。960×640 时列表和属性允许切换显示，不能压掉预览导航与底栏。

标签列表每行显示启用状态、正文摘要、目标及范围。添加生成新 `label_id`，编辑保持身份，删除只去掉所选项。继续提供清除源/配准/输出/全部的便捷动作，所有提交均可撤销。使用现有主题 tokens，不保留固定白底黑字。

### LB-10 对象与范围契约（P0）

- 明确三类目标：源图像栈、配准图像栈、输出结果。输出支持“当前选中结果”及“所有结果”；单项绑定 `output_id`，不绑定行号。无配准栈时禁用并说明原因，不拿源图顶替。
- 栈范围为“全部帧 / 当前帧 / 自定义”。自定义接受 `1-3,7`，面向用户从 1 编号；逆序区间可正规化。非法片段、0、负数、越界均报错，不能静默忽略。显示实际命中数量。
- 当前/自定义范围提交时绑定帧身份，重排后仍指向这些帧；“全部帧”明确包含后来追加的帧。删除帧使对应目标失效，撤销恢复；不整体禁用其他标签。
- 编号采用目标栈当前顺序：`起始值 + (帧号−1)×步长`。范围不另起编号。单幅输出的帧号恒为 1，历史位置不是帧号。
- 多页 TIFF 使用容器路径和页号标识帧。输出重命名、排序及异步插入不改变标签对象。

### LB-11 正文、位置与真实预览（P1）

- 一个“标签内容”输入框支持固定文本与 `{value}`，旁边提供“插入帧编号”。移除两套竞争的格式/自定义文本输入语义。
- 预览提供目标、上一/下一帧、可键入 `n/N`、适应窗口和 100%。目标、内容、颜色、范围、样式均立即刷新。
- 当前帧不在范围内时显示原因并提供“查看首个适用帧”，不写“将显示……”的假成功提示。无图像、空正文、无效范围、越界和绘制失败分别说明。
- X/Y 与字号明确以图像像素为单位，展示坐标原点、文本锚点和边界框。resize 按实际比例调整位置/字号并随变换一起撤销；缩放查看不改标注参数。
- 实际使用所选字体；缺字或字体替代可见。复用项目已有真实字体绘制能力，显示与导出共享布局。16 位数据只有显示副本转 8 位，未覆盖原像素逐值保持。
- 范围无效、正文为空或绘制失败时禁用提交；修正后清除旧错误。导出能区分“不适用”和“应绘制但失败”，后者不能算完整成功。

### LB-12 草稿、提交、取消与持久化（P0）

窗口编辑独立草稿。取消、Esc、× 不修改主状态、工程 dirty、恢复快照和撤销栈。应用一次提交整个变更；新增、编辑、启停、删除均更新 dirty、恢复与撤销。标注撤销只恢复配置和显示，不清空已有配准/输出。

工程版本迁移：旧 `input` → 源栈；旧 `registered` → 配准栈和输出两个适用目标，保留旧效果；旧正文按 `build_label_text()` 原优先级合并。只保留一种运行时模型，旧格式仅在读取边界迁移。

单输出标签可以保存配置和目标身份；若工程不保存该输出像素，重开显示“目标结果未载入”，允许显式重关联，不贴到新输出的同一行。工程保存不解除修饰结果的未导出保护。

## 3. 绘制与导出闭环（P0）

主画布、A/B、预览、单张、右键、拖出、导出全部、文件夹栈、GIF、多页 TIFF 使用同一份目标/范围/编号解析结果。启动导出时固定已提交配置和对象身份，后续修改不改变在途任务。

仅对齐暂存保留未烧入标注的图像；保存时再应用当前配准标签。A/B 缓存包含完整配置或标注版本，跟随模式使用实际显示帧索引。批处理目前没有 GUI 标签接入；本规范不把它描述成已有能力，批处理另见[其规格](07-batch.md)。
