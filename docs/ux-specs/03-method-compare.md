# 方法对比：一致输入、检查范围与采用流程

状态：待实现。依赖 [共用规范](00-shared.md) 和 [主工作流](08-main-workflow.md)。本轮原生 Qt 运行了 OpenFocus B 与 DCT，对比完成、无错误且 worker 已结束；保存了[正常窗口](evidence/compare_ready_zh.png)、[小窗口](evidence/compare_small_zh.png)与[德语深色窗口](evidence/compare_small_dark_de.png)。这些证据不代表下面所有边界已验证。

## 2. 布局

顶部显示来源摘要“参与 N / 共 M 帧 · 尺寸 · 位深 · 配准”；可展开查看排除项和首末文件。随后为方法与参数组；左侧参考图保留检查方框和帧导航，右侧结果卡片按可用宽度换行。

## 3. 输入与参数快照（CP-10，P0）

- 打开时一次捕获 `effective_stack()` 的数组引用、名称、原始帧身份和顺序；不足两帧则明确提示且不启动计算。全不选不能退回 raw_images。
- 换参考帧只改变观察对象，不改变参与集合；名称来自同一快照，不读取后来主窗口列表。
- 记录配准、工作尺寸、核/层数、平滑、曝光、方向、基底、AI 模式等所有实际生效参数；共享现有方法参数定义，不能建立第三套不同默认值。
- “采用参数”与主渲染使用相同参数契约，包括 DTCWT N。主面板需显示或在展开区明确呈现已采用的非默认参数，禁止隐形生效或静默丢弃。
- 保留只读数组引用，避免每次移动检查区复制整栈。若将来允许换来源，先失效全部在途请求，再建新快照。

## 4. 计算与查看分开（CP-11，P1）

| 控件 | 选项 | 语义 |
|---|---|---|
| 计算范围 | 局部预览 / 全图验证 | 决定实际计算像素；ROI 持续标明“不代表完整成图” |
| 查看 | 同步细节 / 整图概览 | 只改变已有结果的显示；概览仅对完整结果开放 |
| 面板大小 | 160–960 逻辑 px，滑块＋数字 | 现有布局控制，明确单位，不称算法分辨率 |
| 检查信息 | x/y、宽×高、倍率 | 显示实际图像坐标及采样范围 |

全图完成后，移动检查区、改面板大小、切概览不重新融合；返回细节恢复中心与倍率。概览保持纵横比。适应窗口指明作用于源图还是结果概览，保留已有同步规则。

ROI 保留当前 halo，不承诺与全图逐像素相同；全图验证是独立操作。UI resize 和全屏变化不清除完整结果，除非真实计算输入改变。

## 5. 状态、取消与失败（CP-12，P1）

每卡片状态为待计算、排队、计算中、当前结果、已过时、失败、已取消。全局明确“配准中”或“正在计算 B，已完成 2/4”；无法取得算法内部进度时显示不定进度，不伪造百分比。

取消后立即显示“正在停止”，禁止重复启动；实际 finished 后才显示已取消。保留仍匹配当前快照的成功卡片。失败卡片提供摘要、详情、重试此方法；重试不清掉其他成功结果。全部完成显示完成数；无方法选中显示下一步。

关闭复用当前 revision/worker/closing 保护，等待合作停止并说明状态；迟到成功、失败及进度都不得更新已关闭/新请求窗口，不使用 terminate。

## 6. 从比较到采用（CP-13，P1；位深与发布为 P0）

点击卡片选候选，显示完整参数摘要。两个操作具有不同结果：

1. **采用参数并返回**：把候选当前有效配置回填主窗口，形成一次可撤销的参数变更；不创建输出、不暗中开始渲染。显示“参数已采用，可生成完整结果”。
2. **以此方法验证全图 → 采用为新输出**：仅 ROI 时先对候选计算完整结果，留在窗口检查；已有当前版本全图时才允许发布。成功后主窗口选中新输出，保留原输出并标明未导出。

只有成功且与当前来源/参数一致的候选能采用；过时、取消、失败和未完成结果均禁用，并解释原因。ROI 裁片不能作为全图输出。正式发布必须使用原始完整 ndarray，不从 QPixmap/QImage 回读。

完整数组和上下文按候选/已计算结果持有，缓存淘汰释放不用的全图；不得为一个显示动作复制八套全栈。发布使用 `OutputManager` 与 `build_render_context`，记录全部有效参数、来源帧、配准/ROI 域、标定。失败保留候选、像素与选择；连续点击只提交一次，成功后才执行历史淘汰。

用户显式采用的比较输出受未导出保护；同步扩展目前仅保护 retouch 的规则，仅设置 `exported=False` 不足够。临时比较结果关闭不触发文件保存确认；保护从正式采用开始。工程仍不保存输出像素。

| 编号 | Given / When | Then |
