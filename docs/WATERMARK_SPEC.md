# 平铺文字水印功能规格

**状态：已实现，本文保留为功能验收依据。** 文中的“必须”是本次交付的要求，默认值是本设计的决定。目标是在 OpenFocus 的源图像帧、配准帧和融合结果上添加创作者自定义的、类似飞书的可见平铺水印，并在不同分辨率下保持合理的一致性。

## 1. 现状和设计边界

- `工具`菜单已有标签和比例尺子菜单；标注在主画布和 A/B 对比视图中预览，在保存时写入副本。
- 图像可能是延迟加载的源帧、配准帧或带独立身份和来源的历史输出；源帧可被局部解码显示。源图、融合用数组和修饰取材不可被标注就地修改。
- 普通结果、源帧目录栈、多页 TIFF、GIF、批处理、拖拽导出及 Linear DNG 有不同保存路径；分层 TIFF 还包含可单独取出的源图层。设计不能只覆盖主窗口的一个保存按钮。
- 这是**可见文字水印**，用于表达署名并提高无意直接使用的门槛。不能声称抵御 AI 修复、裁剪或人为移除；不提供隐形水印、版权登记、加密、在线服务或版权证明。
- 不引入水印图片/Logo、多个水印层、逐帧不同文字或通用排版系统。本次 GUI 功能覆盖下述导出路径；不新增 CLI 参数，不改变 CLI 的既有行为。

## 2. 使用流程与信息架构

1. 在 `工具 → 水印` 中提供 `添加或编辑…` 与 `移除水印`；移除子菜单可按源帧、配准帧、融合结果、全部移除。与标签、比例尺并列，跟随菜单语言切换。
2. 有可预览的源帧、配准帧或融合结果时可打开编辑器。没有图像时禁用入口或展示清楚的空状态；不存在的预览目标不能导致崩溃，也不能暗中改成另一个目标并声称已应用。
3. 编辑器左侧设置文字、外观和作用范围；右侧为真实目标的实时预览，显示所选图像名称、帧号及实际像素尺寸。默认预览当前源帧；没有源帧时选择当前可用结果。可切换可用的源帧/配准帧/融合结果并浏览帧或选择输出；切换预览对象本身不改变应用范围。
4. 输入文字、设置样式，选择作用范围后点击 `应用并关闭`。对话框内是草稿；取消、Esc 和关闭窗口均不改变已提交状态或现有导出。应用后主画布与 A/B 对比立即显示，并作为一个可撤销/重做的动作。没有实际更改时不创建撤销步骤。
5. 编辑器以当前配置初始化，允许重新编辑、调整范围和关闭水印；移除一个目标不影响其他目标。移除已有图像像素中烙入的水印是不可能的，界面不得暗示可以恢复已导出的像素。

### 2.1 作用范围

| 控件 | 应用对象和存续 |
|---|---|
| 源图像帧 | 当前源栈的所有帧，包括被排除出融合但仍可单独导出的帧；不修改磁盘上的源文件 |
| 配准帧 | 当前工作栈产生的配准帧和其相应导出；与源帧和融合结果独立 |
| 融合结果 | 当前工作栈已有的融合/修饰结果与本工作栈之后产生的结果；按输出稳定身份保存生效配置 |

新配置首次添加时默认勾选源图像帧和融合结果，配准帧不默认勾选；尚未产生的融合结果也可预先选中。至少一个对象被勾选且文字有效时才能应用。统一样式可同时应用至多个对象；之后可分别编辑/移除不同对象，不能为一种对象的修改悄悄清除另一种对象。输出记录保有自己的配置，重排/重命名输出不丢失绑定；清空或更换源栈时重置当前栈设置，但仍保留的历史输出保持原有水印设置，不能套上新栈的文字。允许编辑当前选中的历史结果，不得误改其他来源的历史结果。

同一张图像最多有一份本功能的活动水印。`移除 → 融合结果`作用于明确展示/选中的结果；`全部`清除当前源栈、配准栈和所有相关可编辑输出的活动配置。对没有水印的目标执行移除是无副作用操作，状态栏可以提示；不能生成空撤销项。已经烙入像素的输出在界面中明确标记为不可撤销，不能再次叠加活动水印。

### 2.2 界面和默认参数

| 参数 | 交互与默认值 |
|---|---|
| 文字 | 单行 Unicode 自由输入；初始为空，提示示例如 `© 创作者名称`，不自动填入用户名、机器名或日期；最多 80 个 Unicode 字符；仅空白、控制字符或换行无效，保留普通 Unicode 和用户输入的大小写 |
| 字体 | 跟随系统默认，可选择本机字体；显示字体不可用或字符缺失时的回退提示；无法找到可显示全部文字的字体时明确报错，不能静默输出方框或无水印图 |
| 大小 | 相对图像短边的百分比，默认 3.5%，可调 1%–12%，同时提供滑块和可编辑数值 |
| 不透明度 | 默认 28%，可调 5%–90%，滑块与数值同步；5% 是仍可见的下限，避免启用却完全透明 |
| 颜色 | 默认白色，也可选择黑色；配相反颜色的细描边以兼顾亮暗背景，描边和文字随不透明度变化 |
| 角度 | 默认 -25°，可调 -60° 至 60°；指图像坐标中从左到右向上倾斜的默认视觉效果，界面与预览一致 |
| 疏密 | 稀疏 / 标准 / 密集，默认标准；改变相邻文字之间的间距，不能把文字重叠成一团 |
| 恢复默认 | 恢复外观和疏密默认值，保留用户输入文字和当前作用范围 |

对话框采用项目既有明暗主题和可滚动设置区，预览占主要空间；小窗口仍可看到主要预览和固定底部操作按钮。需要的错误、字体替换、不可编辑对象和导出限制直接可见，详细参数解释放控件提示；提供键盘访问、焦点顺序、无障碍名称。12 种语言的文案、提示和错误必须齐全；长翻译、高 DPI、窗口缩小、明暗主题下不遮挡或截断关键操作。

## 3. 跨分辨率平铺与绘制约定

1. 排布基准是**每张实际输出图像的完整像素矩形** `(W, H)`，使用短边 `S=min(W,H)` 计算文字大小和行距，不使用屏幕大小、窗口大小、DPI 或第一帧的固定像素尺寸。应用到不同尺寸的帧时逐帧计算；相同比例的缩放图像在归一化坐标下具有基本一致的字体、密度、角度和相位。
2. 用真实字体度量计算文字边界。以图像中心为稳定锚点，在文字旋转坐标系构建交错行网格，向四边扩展直至覆盖完整图像；文本块及描边不得互相重叠，边缘可自然裁切。稀疏/标准/密集以不同间距实现，不因文本长度或画幅比例导致死循环、极端数量的绘制、只出现中间一块或边缘大面积空白。不能通过循环无上限补铺解决大尺寸或超长文字。
3. 最终的导出尺寸、源帧局部放大区、全图缩略预览都引用**同一整图坐标系和锚点**。区域显示将局部矩形映射回整图坐标，按可见范围计算相交的文字；平移、缩放、切帧、重绘或切换 A/B 不得使图案跳动、重置到局部原点或出现接缝。预览允许抗锯齿/采样误差，位置、角度、大小、颜色和作用范围应与导出一致。
4. 小图需要字号有界且不能让布局为零。文字长到无法以合理大小展示、图像太小以致不可辨认、选中字形无法绘制时，给出明确原因并阻止应用/相关导出；不得静默截断文字、错误地报告成功或写入无水印文件。
5. 导出使用有抗锯齿的字形遮罩，在原始位深上做透明混合。8 位/16 位灰度和 BGR 保持原有尺寸、通道及 `uint8`/`uint16`；对遮罩外的像素要求逐位不变，不能先把整图降到 8 位再升回。16 位边缘混合必须使用原始 16 位底图值。
6. 对 RGBA/BGRA 仅在原有不透明像素范围绘制并保持原 alpha 通道：不能把透明背景变实，也不能破坏 PNG 透明度；若同时启用了已有不支持透明图的标签或比例尺，延续现有明确报错，不将限制伪装成成功。其它格式继续遵守各自现有透明度限制。
7. 文字合成在标签、比例尺之后；水印覆盖在这些标注之上。结果导出保持现有 ICC/EXIF 和色彩路径。预览只做显示用途的转换，不能以预览图替代最终原位深图像。字体解析、文字排版和遮罩应可在后台安全使用；不得在工作线程使用不安全的 `QPixmap` 界面操作。

## 4. 显示与导出契约

用户勾选的目标必须在主窗口相应画布和导出上表现一致。以下路径的水印状态在导出启动时冻结，处理中再次编辑设置不能使同一个文件/栈的前后帧使用不同配置。任何失败都必须遵守现有错误提示、覆盖保护和取消语义；不应写出声称成功但缺少水印的文件。

| 路径 | 必须行为 |
|---|---|
| 源图预览、局部放大、放大镜 | 使用源帧设置，逐帧按完整尺寸定位；注释缓存和局部解码工作者必须随设置修订失效 |
| 结果、配准帧、A/B 滑动对比 | 使用该输出/配准目标的配置；切换历史输出、缩放和擦除对比后保持一致 |
| 当前结果保存、另存为、输出批量保存、拖拽导出 | 按相应输出的冻结配置渲染一次；原始图像和输出内存数组保持不变 |
| 导出源帧/配准帧目录 | 每帧分别以实际尺寸渲染；逐帧处理，保留名称、位深、原有失败报告与源文件保护 |
| 源栈/配准栈多页 TIFF | 每页采用对应目标的水印和该页尺寸；遵守现有临时文件及原子提交机制 |
| 源栈/配准栈 GIF | 每帧采用冻结的目标配置；按既有 GIF 限制量化及取消，不污染源帧 |
| GUI 批处理输出与保存的配准栈 | 在任务启动时冻结相关作用范围与样式；每个实际产物按各自尺寸绘制，产生的已导出记录追踪水印已烙入，重新显示/另存/拖出不得二次叠加 |
| Linear DNG | 沿用现有显示空间标注到相机线性空间的安全映射及可取消检查；不能表示、相机配置不允许或超出色域时明确报错并推荐普通 TIFF/PNG，不能丢水印后成功 |
| 分层 TIFF | 该格式包含可单独提取的源层，必须在导出前明确告知它不会包含当前活动水印；若任一相关范围启用水印，应阻止此导出并引导用户选择已烙入的普通图像/图像栈，直至有完整支持各图层水印的实现。不得将未含水印的分层文件标为已保存了水印 |

`annotations_baked` 目前表示已有标注已经写入，不能单凭该字段推断水印已写入：旧的批处理结果可能有比例尺却没有水印。新增水印的烙入来源须独立追踪，并与已有标签/比例尺的状态区分；只有确实已经烙入的水印才跳过再次绘制。对于仅有导出后像素、无法取得无水印底图的结果，移除或更改活动配置不能承诺抹除像素中的旧水印；应说明并避免在其上叠加新的文字。外部导入图像本身的内容不可识别为可编辑水印。

结果导出保护状态需纳入实际生效的水印配置：改变配置后该结果显示未保存标注；撤销回上次真实导出的状态后恢复已保存；导出完成以导出时的冻结状态记账，不能把正在运行时的后续编辑误记为已保存。

## 5. 状态、项目文件及生命周期

- 水印默认关闭；新建/导入普通源栈不会继承上一个栈的活动水印文字。切换帧、排除帧、重排、旋转、翻转、缩放或重新融合不把水印写入源像素；它根据新图像尺寸和坐标重新计算。初始化/清空当前栈时按其他标注语义清除当前栈水印，并更新相应提示和撤销状态。
- 源、配准和各输出配置包含有效状态、文字、字体、相对大小、不透明度、颜色、角度、疏密；标识必须稳定，不能用列表行号绑定输出。一个输出上的有效配置与所属栈快照明确关联。
- 保存 `.ofproj`、崩溃恢复和更新重启恢复时保存、验证并恢复适用的活动配置；旧工程缺少该字段时视为水印关闭。异常类型、无穷数、非法范围或损坏字段应被安全拒绝或按现有项目校验约定处理，不能让项目加载崩溃或悄悄输出不同水印。工程文件本来不保存结果像素；不得暗示它保存了融合结果或已导出的水印像素。
- 应用、删除、撤销和重做更新工程脏状态、恢复快照、主视图与导出状态；取消草稿不产生这些副作用。可重建的配置不应复制巨幅图像作为撤销快照。
- 水印文字仅保存在用户明确保存的工程及现有本地恢复数据中，不发送网络；日志不记录水印文字。普通图像导出默认包含烙入文字，这是对图像像素的不可逆改变，应在编辑器可见地说明原文件不变、导出副本含水印。

## 6. 性能与实现落点

- 支持常见高分辨率照片和大图：预览采用现有缩略图/局部解码路径；输入文字及拖动控件时合并过期预览请求，不能在 GUI 线程上反复解码或复制整张源图。关闭/切换对象时取消或丢弃过期预览，禁止旧结果覆盖新设置。
- 导出时避免按每个文字块复制整图，不为整栈缓存全分辨率遮罩。优先复用一个字形遮罩、按条带或区域混合，沿用现有内存预算、线程和取消约束；逐帧释放临时数据。性能检查记录图像尺寸、位深和操作，避免只用小图断言性能。
- 推荐新增 `utils/watermark.py` 管理验证、不可变配置、布局、目标尺寸/区域坐标、合成；新增独立 `dialogs/watermark.py` 管理草稿和界面。可按仓库现有惯例增加控制器或轻量状态对象，但不要复制字体解析、文件写入或创建第二套标注导出管线。
- 需要检查的现有接入点：`ui/menus.py`、`main.py` 的注释撤销/刷新及源区域 worker、`controllers/label_manager.py`、`controllers/output_manager.py`、`controllers/export_manager.py`、`widgets/output_list.py`、`core/source_previews.py`、`core/workers.py`、`dialogs/batch.py`、`utils/project_file.py` 和 `utils/recovery.py`。这些是已知线索而不是完整清单；实现者必须检查所有实际调用者和现有测试。
- 国际化扩展十二个语言包。更新中英文用户手册中的工具入口、范围、工程恢复、导出与分层/DNG 限制，并更新 `CHANGELOG.md` 的 Unreleased。

## 7. 验收场景

以下场景须验证真实消费者可见行为，而不是只断言内部函数被调用：

1. **完整流程**：加载源栈，输入中文或英文文字，预览、应用、浏览源帧、融合、保存结果和源栈，读回图像确认水印内容、范围和位置。源文件及融合输入数组逐位不变；不启用时不改变现有结果。
2. **不同尺寸**：同一文字与样式分别用于等比例的 640×480、2560×1920、不同横竖比例和非常小的图像；位置、相对大小/疏密与尺寸规则一致，不重叠、不死循环，小图不能可靠显示时可见报错。切换源帧后没有沿用首帧绝对像素值。
3. **区域一致性**：整图和多个有交叠的局部区域在相同坐标显示相同水印；缩放、平移、源帧切换、A/B 和输出切换后没有跳位、接缝或旧缓存。
4. **位深及透明**：8/16 位灰度和彩色图像导出尺寸/位深不变，遮罩外逐位不变，16 位混合保留原精度；透明 PNG alpha 与底图一致、透明区仍透明。覆盖 JPEG/GIF 的正常量化行为和现有不支持透明格式的错误。
5. **文字和样式**：中文、英文及常见标点可正常绘制；字体缺失/无字形、空白、控制字符、过长文字与极端字号/角度/疏密均有确定行为；亮背景和暗背景上的默认水印可见。
6. **编辑和历史**：取消无更改；应用/移除各作用范围、撤销/重做、项目脏状态与导出保护正确；切换和重命名结果、更新或重开工程、恢复会话以及更换源栈后不串用其他图像的配置。
7. **全部导出入口**：普通保存、另存、批量保存、拖出、源/配准目录、多页 TIFF、GIF、GUI 批处理与可表示的 DNG 分别读回输出；修改导出中的设置不改变已冻结任务。已烙入产物重新导出不叠第二层；分层 TIFF 和不可表示的 DNG 明确拒绝而非静默漏水印。
8. **真实 GUI**：实际启动应用并在明暗主题和小窗口中完成菜单打开、实时预览、修改目标、应用、撤销/重做、取消和一次保存；检查至少中文和一种较长文本语言、高 DPI/缩放与键盘操作。记录实际运行与验证结果。
9. **回归**：运行与标注、图像保存、项目恢复、批处理、GUI 及 i18n 相关的现有测试；只为可能影响用户结果的行为和边界新增稳定测试。测试、文档与功能必须共同满足本文约定；不能只提供界面或渲染原型。
